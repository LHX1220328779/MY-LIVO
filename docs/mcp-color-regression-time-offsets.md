# 彩色点云投歪回归：时间偏移一字两职（MCP 会话 2026-09-26 下半场）

用户反馈：某个历史版本的彩色点云上色边缘/牌面图案明显好于当前 —— 确认为回归，重启排查。

## 排查路径（记录否证，防止重走）

1. 几何锚 sigma 0.05→0.2：牌面跨 epoch 一致性反而更好（21.7→15.5 cm），非回归源。
2. RGB 导出多帧混合假设：体素去重仅删 3.5% 点（每个扫描点只被自己帧着色一次），非主因；
   但去重逻辑保留（rtk_fusion.cpp RGB 导出按像面运动评分 + 3 cm 体素择优）。
3. 相机时间偏移单独扫描（camera 0 / -0.021，即 rel +0.146/+0.125）：白度 25.5/23.7%，更差。
4. 相机→后轴外参 v015 与 v061 有效差 0.33°pitch/0.19°yaw：T3 实验（v061 几何+v015 有效旋转）
   白度仅 54.2% —— 旋转非主因。
5. **T4 实验（v061 几何 + v015 时间对 lidar -0.125/camera -0.115）：白度 79.3%，破案。**

## 根因

`LIVMapper.cpp` 从标定文件 `time_offsets.lidar/camera` 同时覆盖前端
`lidar_time_offset/img_time_offset`。axle 阶段解出的 lidar τ=-0.1459 s 是"扫描 vs INS 位姿"
的对齐量（含 INS 链路延迟），喂给前端后使扫描-IMU 同步错位 21 ms：高角速率段
（近距通过灯柱 ~15°/s）去畸变与图像配对被打花 —— 白灯柱采到背景色、牌面图案涂抹。

判据分离：融合精度对 τ 在 ±30 ms 内平坦（xy max 7.12 vs 7.08 cm），但前端对 21 ms 敏感
（白度 51.5%→79.3%）。正确策略：τ 在融合平坦区内取 IMU 硬件对齐值。

## 量化证据（灯柱白度 = 圆柱内 sat<0.2 且 V>110 占比；近距块=通过段）

| 配置 | 全程 | 远距段 | 近距段 | 融合 xy max |
| --- | --- | --- | --- | --- |
| v061（τ=-0.1459/-0.1211） | 51.5% | 66% | 34% | 7.12 cm |
| v015 复现（-0.125/-0.115 + 旧几何） | 83.0% | 89.6% | 73.3% | — |
| **T4 = v062（-0.125/-0.115 + v061 几何）** | **79.3%** | **88.7%** | **67.4%** | **7.08 cm** |
