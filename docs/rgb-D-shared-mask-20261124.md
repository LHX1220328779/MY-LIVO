# 彩色地图共用强度 D 回波选择（2026-11-24）

用户要求彩色图与强度图使用相同回波处理以降低地图占用。原生 C++ 与标准 Python 导出现在都先使用最终 `map_rows.bin`，再保留同帧有效颜色；距离优先、看穿检查、地面补点及原生0.1m分块过滤均共用。RGB最后仍按3cm体素选择近距离、低转速的最优原始有色观测，坐标和颜色来自同一行，不向其他几何点移植颜色。

原生导出先完成强度掩码，再进入RGB。标准 `--rgb-only` 也核验D来源与掩码；缺少掩码、旧非逐行 `LIVORGB1` 颜色格式会拒绝。配置RGB60m不能扩大原生45m掩码，只可进一步裁剪。
