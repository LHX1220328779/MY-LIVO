# 兴业13：鱼眼标定与 LIVO 相机选择

当前工作区新增鱼眼完整标定流程、独立相机参数与 Studio 相机选择。标定候选必须经过多包、多帧、多阶段及独立路段验证；本轮尚未产生可以替换正式参数的鱼眼精修版本。默认激活版本仍是 `xingye/truck13/v014_camphoto`。

## 输入与投影语义

数据为 `/home/project/data/haibo/xingye/13/20261027/ros2bag`：68 个分包、1020.12 秒，中距和鱼眼各 30600 个视频消息。

鱼眼初值来自原中距标定文件内已有的 `fish_camera[0]`，不另建一套厂家文件。此录制输出的是已整流的广角 pinhole 图像，1920×1080，厂家 K 为 `[508.7092250434, 509.0758442718, 945.8638825396, 490.9500743882]`，D 为五个零。厂家地面曲线与真实雷达叠图均支持该模型；再套等距鱼眼模型会使图像边缘投影产生数百像素偏移。

鱼眼到后轴的初始变换使用根导入版本的参考雷达变换及厂家 `tf_lidar_to_camera`，再顺序应用历史后轴整机修正（含单独的横向修正）。不将后来单个雷达精修或中距相机精修转移给鱼眼。相机切换分别保存 K、D、外参、时间偏移及来源，切回中距可以恢复原参数。

## 操作与验收流程

Studio 当前工作区实例：`http://127.0.0.1:8877`。建图页选择 LIVO 后可选择中距或鱼眼；标定页的相机选择独立保存。

鱼眼完整流水线为：选择同文件鱼眼初值 → 多包光流/IMU 时间诊断 → LIVO 基线 → 多帧灯杆偏航及天际线横滚复核 → 多帧光流/深度内参诊断 → 当前参数 LIVO 基线 → 多视角联合光度标定 → 独立多包固定参数验证 → 候选 LIVO 建图与基线比较。

- 所选窗口必须覆盖至少两个实际携带鱼眼话题的数据包。光度阶段按真正参与计算的视角时间统计相机分包，不把 Perception 包计为相机包。
- 光度拟合每个回波至少被三个视角观测；比较旋转/时间、加 fx/fy、再加残余 k1 的三个模型。空间棋盘格两半互相留出验证，优化器需收敛，复杂模型需额外改善。
- 保持原有一致性要求：旋转每轴差 ≤0.08°、时间差 ≤6 ms、焦距比例差 ≤0.005、k1 差 ≤0.02，两半留出改善均 ≥5%，增加自由度还需额外 ≥2% 改善。
- 独立验证使用不重叠路段，固定候选、禁止重新拟合；每轮也需至少两个相机包。当前参数须与验证快照一致，后续手改不能继承旧验证通过状态。
- CLI、Studio 单步、流水线及手动激活共用鱼眼验收门槛。单帧叠图仅供检查，不能作为标定完成证据。证据不足时允许试验建图，禁止当作正式标定激活。
- 被拒绝的光度结果保存到 `results/calibration_diagnostics/`，保留报告、指标及输入，父版本不变。

命令行从仓库根目录运行（已配置 ROS Humble 的运行容器内）：

```bash
/usr/bin/python3 tools/calib/livo_calib.py camera-select \
  --parent xingye/truck13/v014_camphoto --camera fisheye
bash scripts/run_wuhu_round.sh <新轮次名> --mode livo --camera fisheye \
  --dataset /home/project/data/haibo/xingye/13/20261027/ros2bag \
  --calibration config/carlibration/xingye/truck13/v016_camtime/calibration.json \
  --duration 120 --quick-eval
/usr/bin/python3 tools/calib/livo_calib.py camera-photo \
  --id xingye/truck13/v016_camtime --camera fisheye \
  --bag /home/project/data/haibo/xingye/13/20261027/ros2bag \
  --run results/<训练轮次> --validation-run results/<独立轮次>
```

`--validation-run` 可重复指定。单独运行 camera-photo 用于诊断或精修，正式激活还必须具备前序各阶段与本版本建图闭环证据。上述开发运行默认不导出 PCD，按需保留位姿及去畸变扫描存档；后续按用户明确要求导出的观察地图见下节。

## 已完成的真实开发验证

本次使用独立容器 `my-livo-fisheye`，直接挂载当前工作区，未覆盖原 `calibration` 容器中的另一个代码检出。当前 C++ 实际编译安装成功。

鱼眼早段 0–120 秒及后段 600–720 秒分别完成 1177 帧建图；中距回归完成 1178 帧。播放仅发送选中相机，不出现重复或倒序消息。运行快照保存所选参数及来源，评估从快照 identity 读取标定版本。前后段鱼眼相对 RTK 的融合轨迹最大偏差为 5.79 / 7.36 cm，中距为 6.45 cm。这些是对融合中使用的 RTK 的一致性指标，不是独立真值精度。

全程鱼眼基线 `xingye13_fisheye_baseline_full_20261123` 完成 10176 帧、1017.5 秒有效建图、2904.6 m；68 个输入包共 479382 消息，重复/倒序均为零。融合后相对 RTK 的三维偏差中位/P95/最大为 0.97 / 2.39 / 5.32 cm，距离加权路段 100% 在 10 cm 内；原生前端最终偏差仍为 21.46 m（主要为高度），不能混淆原生与融合后指标。无新 PCD。

使用最终扫描存档检查 30 对重复路段：地面点面距离中位/P90 为 1.57 / 4.91 cm，立面为 1.83 / 6.76 cm；每对地面高度差绝对值中位/P90/最大为 0.31 / 0.59 / 1.01 cm。仅覆盖满足近邻与平面筛选的重访区域，不能作为灯杆或全路地面厚度验收。

修复了两项实际运行问题：CUDA 计算库存在但 NVDEC 库缺失时改用 CPU HEVC 解码，并监测解码器异常退出；内参诊断不再硬取 30 Hz 视频的相邻帧，而是匹配 10 Hz 建图的相邻处理位姿。后者由原来的 0 个可用对变为早段 30 对/3703 对应、后段 35 对/3085 对应，最大图像/位姿时间差 0.000238 ms。

早段灯杆偏航观测分散，后段无可用灯杆；天际线常与激光顶部轮廓不对应，横滚落在搜索边界，均未采纳。光流/深度的两段焦距估计相差明显，仅作为诊断。

后段联合光度训练实际使用 4 个 Camera 包、1136 帧、206 视角及 50000 回波。优化器续算并确认收敛后，最丰富模型两半 fx 比例为 0.941828 / 0.944508，k1 为 −0.051649 / −0.049692，留出改善 26.38% / 27.51%；但旋转 y/z 差 0.1575° / 0.2367° 超过 0.08°，因此拒绝。仅在结果目录保存两半中点实验参数，其独立早段 4 包固定评分改善 19.52% / 19.53%，不能覆盖训练一致性失败。

另用同批多帧光流诊断完整旋转投影 Jacobian：早段流速/陀螺增益从 1.915 降至 1.223，但相关仅 0.723、分段时间差仍 61.1 ms；后段相关 0.553、分段差 752.7 ms。宽视场旋转项解释了部分增益偏差，纯旋转仍不足以分离近景平移及杆臂影响。未将这些无可靠证据的时间估计写入生产参数。

残余 Brown 畸变如通过验收，会在输入端按同 K、同尺寸整流一次，检查有效范围及无折叠后给原 VIO 零畸变 pinhole 图像。未改变 LIO/VIO 残差、雅可比、滤波更新或 RTK 后端。真正的原始等距鱼眼输入目前明确拒绝，需要另行标定其整流模型。

非零 D 的实际 A/B 首轮暴露 OpenCV Mat 浅拷贝导致原始 D 被清零，已标记无效并保留证据。修复为独立副本后重新编译，`xingye13_fisheye_intrinsic_experiment_120b_20261123` 完成 1178 帧，日志明确 `brown_same_K`，D 保留；重映射源坐标全部在图像内、最小局部 Jacobian 为 0.1246。对早段基线，里程比例 0.9987→1.0003，原生偏航 P95 0.4279°→0.3917°，原生终点 XY 1.4415→1.2256 m，但终点三维 3.6120→3.7652 m（高度稍差）。现有 A/B 门槛通过，不能覆盖联合标定一致性失败，候选仍未接受或激活。

已暂存的鱼眼初值版本为 `v015_camselect`，它增加独立鱼眼参数并保持中距参数。`v016_camtime` 仅记录未采纳的时间估计，保留作本地运行溯源，不作为精度改善版本暂存；后续拟合失败材料和实验参数均留在结果目录。
