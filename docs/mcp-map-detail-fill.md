## 2. 误差随距离的变化（4 个灯杆区，全部回波，`range_err.py`）

| 距离段 | 灯杆径向残差 中位 / P10–P90（cm） | 地面相对 <6 m 回波的高差 中位（mm） |
| --- | --- | --- |
| ≤6 / 6–9 m | ≈0 / 2.0–4.1 | 0 / −12 ~ −17 |
| 9–12 m | ≈0 / 4.3–8.0 | −8 ~ +7 |

| 30–45 m | +3.5 ~ +4.9 / 11.5–15.5 | +30 ~ +47 |

- 杆、牌：散布大约每米多 0.3 cm，远处还整体往传感器方向偏 2–5 cm。这是传感器层的光斑 / 角度误差，放回远处回波必然变糊。
- 地面：不同距离段的高度各差 1–5 cm（与 10-20 复核里“各雷达仰视光束高低不一”同源），远处回波直接放回会把地面加厚。但其中正好落在近处地面平面上的那部分，不会加厚。

## 5. 实现（建图程序 `exportMap`，距离优先的第二遍）

- 第一遍不变：每格最近观测 + 看穿格。
- 第二遍 `detailFill`：对第一遍写入的行，按列累加地面层平面，记录 5×5 个 0.1 m 子列是否有行；按格累加二阶矩判定植被，记录 5×5×5 个 0.1 m 子体素。约 18 万个地面平面、4.7 万个植被格，常驻 < 20 MB（第二遍临时 < 100 MB）。
- 导出时：第一遍规则要丢的回波，若是地面层且距该列平面 ≤1 cm、所在子列空，或在植被格且所在子体素空，照样写入。`map_rows.bin` 记录最终决定，评估与 `map_export.py` 自动跟随。
- 开关：`rtk.save_map_priority_fill`（默认 true，属于距离优先；`--no-map-priority` 时一并关闭）。日志 `Saved geometry map` 写明补点行数、平面数、植被格数和第二遍耗时。

## 7. 未解决 / 放弃

- 杆、牌、墙的远处回波：误差是传感器层的（光斑、角度、各雷达仰视光束的高低差），放宽规则只会变糊，放弃。根本办法是逐线束（仰角）内参标定，属于标定阶段的新能力，本次不做。
- 路边矮植被（0.3–1.5 m，位于每列最低两层格内）：地面层只补平面 ±1 cm 内的点，矮植被不受益。要补它需要单独区分“地面层里的植被”，收益与风险未验证，本次不做。
- 彩色地图：着色上限由相机视角决定（只朝前，近处路边、车后看不到），S1 这类牌子没有颜色来源；6 cm 半径是颜色保真的取舍（9 cm 能多着色，但颜色更糊），保持不变。
