## 已确证事实（解读官方灯柱指标必读）

1. **指标本底 ~8cm**：0v2（4.6s 间隔、轨迹误差≈0）分离即 7.9cm——不同视角/遮挡下单杆中位数比较存在不可消除本底；算法性重影分量 ≈ √(总²−8²)。
2. **指标混构污染**：z≈48.0m 带混入灯臂/线缆簇（era0 X≈−10.7, 66-95 点 vs era10 17 点），主导 P95/max 带；杆身解读用 45.5-48.0m 带（0-5m 对中位恒 ~4-6cm）。
3. **era0↔era10 系统偏移 (+12,-11)cm** 在所有版本稳定存在（杆身带中位：era0 X≈−11.12, era10 X≈−11.00）。
4. **重影主要产生于 t≈215-227**（修正量爬升段）：89 分对 0v5=5.2cm、5v10=16.4cm。
5. **灯柱顶部无法跨时代评估**：era0（55m 远）map_0 在 Z≥52m 仅 ~5 个回波，无共视顶面；顶部 12 个同可见性 cell 无法逐点证实同一物理面。
6. **起步 IMU 异侧 ~52-57/77 为幅值 <1.3cm 的参考系伪影**：后轴已贴 RTK（cross-track 中位 +0.2cm），IMU 点偏差主要来自参考折线的原生姿态×杆臂投影。
