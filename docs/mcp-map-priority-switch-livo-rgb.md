## 1. map_10.pcd 现象与原因

- 分块（`map_N.pcd`）按扫描时间顺序每 100 万行切一块。距离优先是全局规则：同一个 0.5 m 格只保留最近有效观测附近的回波。往返路段上，一个面在去程从 14–17 m 看到、在回程从 6–8 m 看到，它的行就都写进回程的分块；去程分块里只剩去程自己最近的观测，即车身附近。
- 原型统计（mcp18 存档，4 个灯柱区域）：开距离优先时，每帧在区域内的行只保留中位 5.6–12.5 %（>15 m 的行只保留 3.1–7.3 %）；关闭时 100 %。整图并集：1 m 列覆盖只少 0.05 %，0.5 m 格少 2.3 %。
- 单向路段：只被远处看到的格子会保留远处回波，整图覆盖不受影响；但按分块看，仍然每块只剩它自己的近处观测。按分块使用或检查时，这确实会表现为“扫描范围很小”。
- 实例（`results/.mcp/rgbtest/chunks600.png`）：第 600 帧开距离优先时落在 map_8.pcd，这一块只有本车道和右侧路边；关闭时落在 map_27.pcd，两侧路边和对向车道都在。开关打开的 mcp22b 与原来的 mcp18 分块相同。
- 默认关闭后，分块恢复为各自扫描的全部回波，灯柱和对向车道都在；代价是往返重影回到全部回波的水平（灯柱壳宽约 12 cm）。

## 2. 开关

| 位置 | 用法 |
| --- | --- |
| yaml | `rtk.save_map_priority_enabled: false`（默认），比例 / 余量 / 格 / 看穿距离保持 1.5 / 2 m / 0.5 m / 25 m，开启时生效 |
| 脚本 | `scripts/run_wuhu_round.sh ... --map-priority` 开启 |
| Studio | 建图页开关“地图距离优先（去掉被别处更近看到的远处回波，分块只剩近处）”，默认不勾 |
| 标准地图 | `tools/livo/map_export.py` 跟随本轮开关：关时导出全部回波，开时读 `map_rows.bin`；更早的轮次没有开关参数时，有距离优先参数视为开，否则视为关；`--priority-ratio` 仍可强制指定 |

关闭时不写 `map_rows.bin`，评估按全部回波逐行配对（与距离优先之前相同）。建图日志会写明 `range priority: ON / off`。

## 3. 替代方法核查：一致性筛选

思路：只删与近处观测矛盾的远处回波。远处回波离任意近处回波 ≤ d 就保留，看穿检查照旧。原型 `results/.mcp/rp_cons.py`，规则与建图程序相同，4 个区域，mcp18 存档：

| 方案 | 每帧保留（>15 m 行 / 全部行，中位） | 灯柱壳宽 cm（固定圆）0 1 4 5 6 7 8 | 地面厚度 mm |
| --- | --- | --- | --- |
| 关（全部回波） | 100 / 100 % | 8.7 8.8 9.0 10.9 9.7 17.1 9.2 | 48–60 |
| 距离优先 | 3–7 / 6–13 % | 2.7 2.7 3.0 5.2 3.0 4.7 2.8 | 40–44 |
| 一致性 d=3 cm | 17–24 / 21–35 % | 3.7 3.4 4.0 5.7 4.4 5.7 3.9 | 35–41 |
| 一致性 d=5 cm | 29–39 / 32–54 % | 5.0 4.6 5.4 6.9 6.3 7.0 5.0 | 39–47 |
| 一致性 d=8 cm | 37–51 / 40–66 % | 6.2 5.7 6.6 7.7 7.2 8.5 6.3 | 43–54 |

- 远处回波大量丢掉，并不是因为阈值太严。远处地面回波整体偏高约 3 cm（全部回波时地面带平均抬高 30.6 mm），远处细物体的边缘展宽到 12–20 cm，所以“删得越少、重影越大”是连续的取舍，没有一个点能同时保住分块的完整和去掉重影。
- 遍内或分块内的距离优先能让分块完整，但往返两份拷贝分在不同分块里，并集的重影不变。
- 结论：没有比“开关 + 默认关”更合适的方案，放弃；需要干净灯柱时手动开启距离优先。

## 4. LIVO 灯柱重影比 LIO 大：溯源

| 产物 | LIVO | LIO |
| --- | --- | --- |
| map_N.pcd 行，全部回波（livo_11 / lio_9） | 12.6 | 12.2 |
| map_N.pcd 行，距离优先（mcp18 / mcp19） | 3.0 | 3.9 |
| global_map.pcd，5 cm 体素，距离优先（mcp18 / mcp19） | 7.2 | 7.0 |
| 彩色地图 rgb_map_N / global_map_rgb（livo_11、mcp18，修复前） | **18.2** | 无 |

（灯柱壳宽中位，cm，9 根，1–7 m 高度每 0.5 m 一个圆的径向残差 P10–P90，`results/.mcp/pcd_shell.py`。体素地图因密度被拉平，稀疏的远处点占比变大，数值普遍高于行级。）

- 几何地图两种模式相同，轨迹也相同（0.96–0.97 / 3.4–3.7 / 6.9–7.1 cm）。差别只在 LIVO 才有的彩色地图上，而且它与开不开距离优先无关（livo_11 与 mcp18 都是 18.2）。
- 不是标定、位姿或时间错位：colors.bin 的每个彩色点与同一帧 scans.bin 回波按原生位姿投影后，最近距离中位 0.01 mm、最大 0.0 mm（抽查 8 帧）。彩色点就是同一批 LiDAR 回波，相机标定只决定哪些回波着色、着什么颜色，不改变几何。
- 原因：彩色地图只收“落在前视相机视锥（60×32°）里的回波”。对路边灯柱，它们全部来自车前 16–60 m：灯柱 0/1/4/5/6/7/8 的彩色回波没有一个近于 15 m（最近 15.7–20.8 m），15–25 m 占 13–37 %，25–40 m 占 32–49 %，40–60 m 占 9–45 %。车开到灯柱侧面 6–8 m 时它已出了视锥，这些最清楚的近处观测从来进不了彩色地图。再加上 60 m 着色截断、每 3 cm 体素一个点，远距离展宽被完整保留下来。
- 修复（建图程序 `exportMap` + `map_export.py`）：彩色观测只提供颜色。每 3 cm 体素取最佳观测的颜色（距离 + 20 m×rad/s 转速，沿用原来的评分），找不到再查 6 cm 体素。几何来自几何行：`rgb_map_K.pcd` = `map_K.pcd` 中能着色的行（同序号、同一批行），`global_map_rgb.pcd` = `global_map.pcd` 中能着色的点。这样彩色地图的几何与 LIO 地图按定义一致，开不开距离优先都一样。
