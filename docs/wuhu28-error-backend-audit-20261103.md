## 算法修改

Frame 保留前端世界系速度，用梯形积分预测相邻原生位移：

```
predicted_step = 0.5 * dt * (previous_velocity + current_velocity)
defect = norm(current_native_position - previous_native_position - predicted_step)
```

仍使用原 5 cm 门槛、0.5 s 最大短间隔，以及真实跳变两侧立即插节点的机制。检测在同一原生世界系内完成，不将 RTK/INS 波动当作前端重定位。未减输入点、关闭约束、冻结历史姿态、截断图、降低迭代次数或改噪声/鲁棒核。

旧结果 7,129 帧的原生位移/速度缺陷最大约 3.18 cm，超过 5 cm 的数量为 0；前端预测/更新日志按时间对齐后，位置更新最大约 4.81 cm。大量旧触发是平滑失配，不是需要加节点的瞬时重置。

Studio 的自动标定选择现在优先本录制已有正式版本；手动子版本继承父链来源，临时 scan/advisory 不自动选择。当前激活版本本就匹配录制时继续使用；没有匹配版本时保留激活项。显式人工选择仍保留。未更改全局 registry：10 月 26 日数据继续匹配 v036，9 月 28 日匹配 v030，xingye13 仍匹配 v014。

建图页标注各版本来源，默认选项改成按录制匹配，避免界面仍声称执行全车最新激活项。
